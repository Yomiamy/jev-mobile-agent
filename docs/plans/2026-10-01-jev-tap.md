# mobile_tap（Jev 依描述點擊）實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> 本文件為事後補記的 STAGE 0b 計畫：Task 1–4 已在 `feat/jev-decision` 完成（已勾選並附 commit），Task 5 起為後續工作。

**Goal:** 讓 agent 以一句描述點擊元素，由 Jev 從精簡後的元素表中選出目標，沒把握就不點。

**Architecture:** 新增 `compactElements` 精簡無障礙樹（`list` 輸出同步受惠）；`src/jev.ts` 將元素表組成一個 TypeSafe Choice 問題並解析回答；`mobile_tap` 串起 dump → 精簡 → Jev →（必要時 OCR 再問一次）→ 以 ref 或中心點點擊，ref 失效時重讀一次。

**Tech Stack:** TypeScript（Node ≥ 20，原生 `fetch`）、`@modelcontextprotocol/server`、`zod`、mobilecli、TypeSafe `POST /v1/systemone`（`jev-latest`）、`@playwright/test`（單元測試）。

**Spec:** `docs/features/2026-10-01-jev-tap.md`

## Global Constraints

- 未設定 `TYPESAFE_API_KEY` 時不註冊 `mobile_tap`，既有工具行為與輸出格式以外的一切維持不變。
- 不新增 npm 相依（用 Node 內建 `fetch` 與 `AbortSignal.timeout`）。
- 邏輯放新檔（`src/compact-elements.ts`、`src/jev.ts`），`src/server.ts` 只加最少接線，降低與上游 mobile-mcp 同步時的衝突。
- Jev 回答只能映射到觀察到的元素；任何無效回答、HTTP 錯誤、逾時都不得點擊。
- 信心門檻 `MIN_CONFIDENCE = 0.5`；TypeSafe 請求逾時 15 秒；Choice 選項上限 255。
- 文件（`docs/`、README.zh-TW）以繁體中文撰寫；commit 訊息英文。

- [x] **Step 1: 寫測試**：畫面外（含 x 為負的前一頁）被移除、部分可見保留；空容器移除、純圖示 `Button`／`ImageButton` 保留；重複 label 只留第一次、子節點保留自己的 `text`；螢幕尺寸未知時不過濾位置。
- [x] **Step 2: 實作**

```ts
const INTERACTIVE_TYPE = /Button|EditText|TextField|SearchField|Switch|CheckBox|Radio|Slider/i;

export const compactElements = (elements: ScreenElement[], screen: Dimensions): ScreenElement[] => {
	const seen = new Set<string>();
	return elements
		.filter(e => (!isKnown(screen) || isOnScreen(e, screen)) && hasContent(e))
		.map(e => {
			if (!e.label) return e;
			if (seen.has(e.label)) return { ...e, label: undefined };
			seen.add(e.label);
			return e;
		});
};
```

- [x] **Step 3: 接到 `list`**：`elements = compactElements(elements, await robot.getScreenSize());`（在 OCR 合併之後、`formatElements` 之前）。
- [x] **Step 4: 驗證**：`npx playwright test test/compact-elements.test.ts` → PASS；FindRestaurant 首頁 7,681 → 3,089 字元。
